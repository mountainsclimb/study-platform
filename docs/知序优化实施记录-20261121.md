#### 验收过程中发现并修复的集成问题（记录在案）

1. **公网自检误伤 CI/本地**：`config_guard._deployment_layout` 原先把「设置了 `STUDY_BANK_DIR`/`STUDY_DATA_DIR`」一律当部署布局，
   而 `ci_accept`/测试会把题库固定到本机 r5 目录，导致公网模式用例被 fail-closed 判死；
   已改为显式 `STUDY_DEPLOYMENT_LAYOUT=1`（Compose 已设）或标准 `/data`、`/bank` 路径判定，并补回归测试。
2. **本机系统代理劫持 127.0.0.1**：`seed_demo.py` 的 httpx 默认 `trust_env=True`，在配置了系统代理的 Windows 上访问
   `127.0.0.1:8840` 得到 HTTP 502；已改为 `trust_env=False`（脚本只访问本机实例），演示账号/数据可正常注入。
3. **验收 UI 阶段可重复性**：`ui_check_upload.py` 注册临时账号遇 409 时改为回退登录；整合模块端到端改为 `--seed` 自带演示数据，
   验收不再依赖人工预置实例。
