## 2. 课堂演示场景数据与接口

### 2.1 场景契约（`app/classroom/schema.py`）

- `SCENE_TYPES` 保持 `slide/quiz/interactive/pbl`（AI 生成白名单不变）；新增
  `MANUAL_SCENE_TYPES=("demo",)`、`ALL_SCENE_TYPES`、`SCENE_TYPE_LABELS["demo"]="原理演示"`；
  别名 `demo/principle/演示/原理演示 → demo`（AI 生成输出若出现 demo 仍按旧规则降级为 slide）。
- `normalize_demo_content(raw)`：校验并冻结
  `{artifact:{artifact_id,revision,kind,title,data,preview},source_note,assumptions,step_count}`：
  artifact_id 格式、revision 1..100000、kind ∈ 6 类演示附件、data JSON ≤200KB、preview PNG dataURI 解码 ≤200KB
  （或 SVG ≤60KB）、整个 content ≤260KB、source_note ≤300、假设 ≤6×200、步骤 0..50；
  输出补 `type="demo"`、`fixed=true`、`fixed_revision`，并给出「固定版本」中文警告。

### 2.2 接口（`app/classroom/api.py`）

| 方法/路径 | 说明 |
| --- | --- |
| `GET /api/classroom/meta` | 只追加 `manual_scene_types:["demo"]`、`demo_artifact_kinds:{demo:[6 类]}`、`limits.demo_content_bytes`；既有 `scene_types` 仍 4 类。 |
| `POST /api/classroom/courses/{id}/scenes/demo` | body `{artifact_id,revision?,title?,source_note?}`；201 `{scene,course}`。课程归属 404、运行中课程任务 409、场景数超限 409、他人/不存在附件 404、kind 非法 422、内容超限 422。 |
| `DELETE /api/classroom/courses/{id}/scenes/{scene_id}` | 仅 demo（其他类型 409）；删除后 `order_index` 重排连续；返回 `{deleted,scene_id,course}`。 |

生成/重生成/会话/测验/素材/场景 HTML 等既有路由不变；`/scenes/{id}/html` 对 demo 返回 404 中文（不直出 HTML）。

### 2.3 固定版本导出（`app/classroom/exports.py`）

- **PPTX**：demo 独立页（`_pptx_demo_slide`）：标题、「原理演示 · kind 中文 · 固定版本 vN」、artifact 标题/ID、
  出处与假设、步骤数；`preview.png` 可解码时插入图片（等比），否则中文提示「请在知序课堂中播放」；
  备注写固定版本与 artifact_id。
- **离线 HTML / 打印 HTML（PDF 自动生效）**：静态段落 `section.cls-demo-scene[data-scene-type="demo"]
  [data-artifact-id][data-fixed-revision]`：徽标、标题、PNG dataURI、出处、假设、步骤数、
  `<script type="application/json">` 内嵌快照（`</script>` 已转义）；播放器壳新增只读 `renderDemo`
  （不执行附件内容、无外链）。
- **ZIP**：额外 `demos/scene-<NN>-<artifact_id>.json`（快照 + 固定版本说明），manifest 追加 `demoScenes`
  与 `capabilities: demo-scenes`；课程快照 `scenes/*.json` 保留完整 demo content；资源包内 PPTX 同样固定版本。
- **导入（`app/classroom/importer.py`）**：放开 demo 场景白名单并用 `normalize_demo_content` 重新校验，
  导回后仍为原固定版本；旧 ZIP（无 demo）行为不变。

## 3. 前端

### 3.1 课堂播放器（`web/js/components/classroomPlayer.js`）

- `scene_type==="demo"` → `.cls-demo-stage`：标题、固定版本徽标、kind 中文、步骤数；按 kind 懒加载只读组件
  （flow/isometric/3d/science → `renderPrincipleDemo`；function_graph → `createFunctionGraph(readOnly)`；
  whiteboard → `createSketchBoard(readOnly)`）；渲染完成设 `data-demo-ready="1"` 并广播
  `zhixu:demo-ready`；失败中文降级 + 海报；退出/切换销毁组件与计时器；键盘避免与演示内步进冲突。

### 3.2 课堂页（`web/js/pages/classroom.js`）

- 「插入演示」弹层：并行读取六类演示附件（去重/排序/失败忽略该类），插入 POST 固定当前版本，
  成功 toast「已插入演示（固定版本 vN）」并刷新；「课堂演示场景」管理列表支持删除（confirm，仅删场景）；
  空列表中文引导；错误展示后端 detail。

### 3.3 笔记页（`web/js/pages/notes.js`）

- 笔记详情「学习附件」区：`GET /api/artifacts/by-target?target_kind=note&target_key=<note id>`；
  只读打开（演示/函数图/白板）、下载海报、显示失效数量；无数据隐藏、接口不可用中文降级；
  不影响既有资料定位/摘录/笔记编辑发布。

### 3.4 SeeCode 手绘与学科示例（`web/vendor/principles/*`、`question.js`）

- `flow.js`：`layout: flow|loop|timeline|state`、`style: clean|sketch`；节点 `start/process/branch/end/state/event`、
  边 `solid/dashed/feedback`；timeline 水平轴、state 环形状态图、loop 回边；手绘风格用 id 哈希播种的
  确定性抖动（双描边/轻微旋转），无随机数，重放/海报一致；既有 flow 渲染字节级不变。
- `iso.js`：`parts[].shape: box|cylinder|gear|plate|rod`、`part.description`、多行 `labels`、
  `style: clean|sketch`；拆解/装配、步骤高亮、海报保持；未知 shape 回退 box。
- 新增 5 预设（见 §1），均含 `title/source/assumptions/subjectHints`，来源标注「本地教学示意」。
- `question.js`：「查看原理」按学科推荐默认（物理/机械→齿轮流程；数学→函数时间轴；生物→气孔结构；
  化学→光合状态图；科学→复习闭环），下拉切换全部 8 个预设（按 kind 分组、推荐标记）；保存附件带
  `source_ref`=预设 id；旧附件按 kind 兜底。

## 5. 兼容与回退

- AI 生成场景类型、`/meta.scene_types`、既有课堂流程/测验/会话/多智能体、旧 ZIP 导入、既有导出输出均不变；
  demo 为**新增手工场景类型**，不参与 AI 生成。
- 导出对 demo 仅内嵌静态快照与只读渲染，不执行附件内容、不引外链；旧课程无 demo 时输出与之前一致。
- 前端组件/接口不可用时中文降级；删除演示只删课堂场景，不删学习附件。
- 已知边界：ZIP 中的 demo 为「固定版本静态快照 + 数据 JSON」，不是完整离线交互播放器（离线交互版留待
  M6 互动讲义）；课堂视频可捕获演示静态画面，未做 demo 视频专项 e2e（既有视频测试全绿）。
