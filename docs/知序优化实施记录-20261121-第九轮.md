## 2. 模板库与 API（`app/demo_library.py`，路由前缀 `/api/demos`）

| 方法/路径 | 请求 | 响应要点 |
| --- | --- | --- |
| `GET /api/demos/templates` | — | `{items:[{template_id,kind,title,description,parametric:true,params:[{name,label,type:int/float/list,default,min,max,step,unit,length?}],assumptions,source_note}],total}` |
| `POST /api/demos/build` | `{template_id, params?}` | `{template_id,kind,title,seed,params,data,assumptions,source_note}`（不落库，确定性） |
| `POST /api/demos/simulate` | `{template_id:"factory-line", params?}` | `{run:{run_id,template_id,seed,params,result,created_at},deterministic:true}`；仅工厂类模板可持久化 |
| `GET /api/demos/simulate/{run_id}` | — | `{run}`；他人/不存在 404 |

### 模板与参数

| template_id | kind | 参数（默认 / 范围） | 数据要点 |
| --- | --- | --- | --- |
| `gearbox-3d` | `mech_3d` | seed、input_rpm 1200(300–3000)、driver_teeth 12(10–40)、driven_teeth 48(20–80)、module_mm 2(1–5) | 7 部件（含 parent 树）、4 拆解步骤（explode 0→1）、6 读数、camera、假设×4 |
| `pump-3d` | `mech_3d` | seed、stroke_mm 60(20–120)、rpm 180(60–600)、bore_mm 60(30–120) | 缸体/活塞/连杆/曲轴/进排气阀 7 部件、4 步骤、行程/排量/理论流量/活塞均速/角速度 5 读数 |
| `factory-line` | `factory_sim` | seed、sim_seconds 180(60–600)、arrival_interval_s 8(4–20)、service_s [6,4,8]（每项 2–30，长度 3）、buffer_capacity 5(1–20) | flow 节点/边、station_labels、metrics、events、假设、来源说明 |
| `factory-line-2d` | `flow_animation` | 同 factory-line | 复用 DES 结果生成流程演示数据，可直接保存为流程动画附件 |

- 机械读数均为工程公式 + 逐条「教学近似」标注：速比=driven/driver、输出转速=input_rpm/速比、
  扭矩放大≈速比、分度圆直径=m·z、中心距=(d1+d2)/2；泵：V=π(b/2)²·s、Q=V·n、v=2sn/60、ω=2πn/60。
- 所有响应回显 `seed`；数据 `basis="local-teaching"`（机械）/`"deterministic-des"`（工厂）。

### DES 口径

- 唯一随机源 `random.Random(seed)`；固定抽取顺序「每个物料先到达间隔 → 工位 0→2 服务时间」，
  不依赖系统时间/进程随机/哈希序；同 `template_id+params+seed` 逐字段可复现（跨进程已验证）。
- 三工位串行、每工位单服务台 + 输入队列容量 `buffer_capacity`，下游满则阻塞、首站队列满丢弃；
  事件堆同刻先「服务结束」后「到达」。
- 事件：`{t(5 位小数),type,station:0-2,item_id,queue}`，按 `(t, 固定类型序, station, item_id)` 稳定排序，
  最多 2000 条（超出截断并在 assumptions 说明，指标仍按全量事件计算）。
- 指标：`sim_seconds/arrivals/completed/throughput_per_min/avg_wait_s[3]/max_queue[3]/utilization[3]/
  bottleneck_station/bottleneck_reason/dropped/blocked`；瓶颈按（平均等待主序，利用率次序）取最大并给中文原因。

## 3. 前端组件（§5.4）

### 3.1 机械 3D（`web/js/components/mechDemo.js`）

- `createMechView(container, demo, options)`：本地 three.js 只读渲染；部件树按 `parts[].kind`
  （box/plate/cylinder/rod/gear）与 `parent` 递归构建；鼠标拖拽旋转/滚轮缩放；拆解滑块与步骤推进；
  剖切开关 + 切面位置（`renderer.localClippingEnabled` + `material.clippingPlanes`）；运转播放（齿轮/轴
  视觉角速度由读数推导，不修改数值）；读数/部件/步骤侧栏；`onFrameReady({step,mode,seed})`。
- 无 WebGL / three 加载失败：渲染本地等距 SVG 示意图（部件高亮/引线/读数/部件列表）+ 中文提示
  「当前设备不支持 3D，已切换为示意图」，运转禁用、步进可用；`getMode()` 返回 `three|svg`；destroy 释放
  geometry/material/renderer（`forceContextLoss`）与监听。
- `openMechDemo({template_id, artifact, ...})`：弹层优先读 `/api/demos/templates`，按 kind `build`/`simulate`，
  失败回退本地 `MECH_PRESETS`（中文标注「本地教学示意（只读数据）」）；参数只读展示；「保存为学习附件」
  走 `/api/artifacts`（kind `mech_3d`/`factory_sim`，`source_ref=template_id`，links 到题目），失败中文提示。

### 3.2 工厂回放（`createFactoryView`）

- 指标卡（吞吐/完成-到达/瓶颈工位+原因/仿真时长）、三工位流程图（状态/队列/利用率/平均等待/最大队列）、
  队列长度时间序列（按 events 聚合 3 线 + 时间游标）、迷你 2D 产线、事件回放时间轴（播放/暂停/倍速/拖动）；
  `onFrameReady({t})`；事件只回放不重算，缺事件时只展示指标/结构并注明不伪造回放。

### 3.3 页面接入

- 题目页：「机械演示」按钮（物理/机械/技术，默认模板 物理→pump-3d、机械→gearbox-3d、技术→factory-line），
  懒加载组件、参数只读、保存附件链接题目。
- 课堂播放器：`DEMO_KIND_META` 增加「机械 3D」「工厂仿真」，`mech_3d/factory_sim` 只读渲染并沿用
  `data-demo-ready="1"` + `zhixu:demo-ready`；mech 无 step_count 时用 `data.steps.length` 显示步数。
- 笔记附件面板：kind 标签与只读打开分支；未知类型仍中文提示「暂不支持在页面内打开」。
- 新增 `web/styles-mech.css`（`.m5-` 前缀，深色/移动端），由 `web/index.html` 加载。
