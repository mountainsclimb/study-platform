# 开源组件整合实施记录（2026-11-23，批次一 / 二 / 四）

对应方案：`../docs/开源组件整合实施方案-通用版.md`（工作版基线 `c79270f`）。
本轮按方案推荐顺序落地**批次一（质量工程）、批次二（识别与输入闭环）、批次四（本地向量与重排）**，
批次三（离线语音）、批次五（演示与可视化）、批次六（词汇模块）、可选 PhET 与进阶项未实施，
原因与后续入口见文末。

工程原则保持不变：每项都是「可选依赖 / vendor 资产 + 独立适配模块 + 未启用即现状」，
独立可验收、可单独回退；新字段只做加法。

  `formula` / `table` 两个引擎状态段。

### 2.3 RapidTable 表格结构（方案 §3.2）

- 新模块 `app/ai/table_structure.py`：`recognize_table(crop, *, ocr_results=None)`；
  - 输出先经服务端 `sanitize_table_html()`：白名单只留 `table/thead/tbody/tr/td/th` 与
    `rowspan/colspan`（1–50），剥离全部其它标签、事件属性、style、script/style 内容；
  - 超过 20000 字符抛 `ValueError`；返回 `{"html", "row_count", "col_count", "elapsed_ms"}`。
- `enrich_blocks` 只把同页连续表格块的第一块写入 `table_html` / `row_count` / `col_count` /
  `table_engine` / `table_span`，组内其余块不变；单组最多 20 块、区域面积不超过页面 85%。
- 白名单：`notes_agent._normalize_ocr_blocks()` 增加 `table_html` / `row_count` / `col_count`；
  `_validate_confirm_blocks()` 对非法/超长 `table_html` **丢弃字段**并在响应 `block_notices`
  说明，不整单 422。
- 开关：`STUDY_TABLE_OCR=on`（默认 off）、`STUDY_TABLE_TIMEOUT`（默认 8）。
- 前端：拍题校对面板对带 `table_html` 的表格块显示「含表格结构」与只读预览（DOMPurify 白名单兜底）；
  `web/js/core/dom.js` 的 `tableBlockNode()` 优先用 `table_html` 渲染表格，缺失时回退原文字/行列路径。

- 可选依赖：`requirements-embeddings.txt`（`fastembed==0.9.1`，Apache-2.0）。
- 新模块 `app/ai/embeddings_local.py`：

    加载；目录缺失/依赖缺失/初始化失败转成 `LocalEmbeddingUnavailable`，可 `reset_engine()` 重试；
  - `embed(texts)` / `rerank(query, texts)` 同步执行，进程级信号量限制并发 2。
- `embeddings.py`：
  - `EMBEDDING_MODES` 增加 `"local"`；
  - `_local_config()` 返回 `EmbeddingConfig(endpoint="local://<模型名>", source="local")`，
    沿用 `storage_model` 标签，本地向量与任何 HTTP 模型天然隔离；

  - `_embed()` 对 `source == "local"` 走 `asyncio.to_thread(embeddings_local.embed)`，
    **不进入** `_request_embeddings()`；
  - `embedding_status()` / `test_embedding_config()` 如实返回本地来源、维度、耗时。
- 重排：
  - 新模块 `app/ai/rerank.py`（`available` / `rerank` / `score_texts`）；
  - `search_vector.rank_chunks_hybrid()` 增加可选 `rerank`：取混合得分前 20 条，
    最终得分 `0.3 × 混合（归一化 0–1） + 0.7 × 重排（min-max 归一化）`，返回结构不变；
  - `practice.search_similar_questions()` 在候选打分后重排，条目增加 `rerank_score`
    （4 位小数）；`similarity` 与 `exact_match` 语义不变；重排失败沿用原排序。
- 设置页：`settings.js` 增加「本地模型（离线）」选项；`local_available` 为假时置灰并说明；
  `renderEmbeddingStatus()` 显示本地模型名/维度；新增 5 个 `settings.embedding*` 中英文键。
- 运维：`app/ops.py` 的 `_BACKUP_EXCLUDED_ENTRIES` 增加 `"models"`；备份目录白名单不变。

## 5.1 代码审查修正（2026-11-23）

- 公式后处理的单块超时改为「拿到推理槽位后才开始计时」（`asyncio.Semaphore` 包住
  `wait_for`），避免 20 个块同时排队时后半个块被误判 timeout。
- 笔记检索的混合打分与重排整体移入 `asyncio.to_thread`；拍题识别任务里的相似题检索
  也改为 `await asyncio.to_thread(...)`；相似题重排只取相似度前 20 条，避免阻塞事件循环。
- 表格裁剪的 OCR 框按**实际裁图原点**（含 2px 补白）换算，修正单元格错位。
- 去重脚本的 `--max-pairs` 改为跨学科全局上限；删除永远不会命中的长度比快速排除死代码。
- MathLive 脚本 `load` 后若 15 秒内未定义 `<math-field>`，自动回退文本输入，不再永久挂起。

## 6. 已知限制与风险

1. **公式/表格真实模型未安装**：本轮用假引擎覆盖降级与接入；真实识别率需按方案验收
   （20 张公式裁图记录可渲染率、含表格试卷截图人工核对）。
2. **`rapid-latex-ocr` 的 numpy 约束**：包声明 `numpy<2.0.0`；`requirements-formula.txt`
   固定 `numpy==1.26.4`。若部署必须 numpy 2，请把公式识别放入独立 venv/进程。
3. **fastembed 离线目录**：`TextEmbedding(cache_dir=..., local_files_only=True)` 的目录结构
   与 `bge` 模型文件放置方式是本项的第一个验证点；本轮未下载真实模型，需在验收环境实测。
4. **旁白本地候选未接**：`classroom/narration.py` 在无厂商连接时仍抛 422；这是批次三的
   关键剩余项，未在本轮半途接入。
5. **Surya 仍保留文件**：本轮只移除能力位并加注记，按方案在下个版本周期删除模块、测试与
   `requirements-surya.txt`。
6. **axe 基线**：本轮修复后主要路由已零 critical/serious；后续新增页面仍需在 `-Ui` 验收
   中跑 `ui-a11y`，出现新增违规即失败。
