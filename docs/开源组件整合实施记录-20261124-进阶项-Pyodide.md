# 开源组件整合实施记录（2026-11-24，§9 进阶项：Pyodide 浏览器内 Python）

对应验证报告：`../docs/开源组件整合进阶项验证-20261124.md`。验证结论为“条件 GO：
只能做独立策略专用页”；本记录为专用页的最小落点，不接入主站 SPA 与课堂交互沙箱。

---

## 1. 资产（`web/vendor/pyodide/`）

- Pyodide **0.28.0** 核心：`pyodide.js`（16,811）、`pyodide.asm.js`（1,072,130）、
  `pyodide.asm.wasm`（8,645,010）、`python_stdlib.zip`（2,416,414）、
  `pyodide-lock.json`（108,703），合计约 **11.9MB**；许可 `LICENSE`（MPL-2.0，
  内置 CPython 为 PSF）。
- 与 `web/vendor/pyodide/README.md` 登记的大小/SHA-256 一致；测试逐文件校验。
- 同源分发，无 CDN；不随仓库分发额外包与 source map。

## 2. 专用页（`web/lab/python.html` + `python.js` + `python.css`）

- `GET /lab/python`（登录）由 `app/main.py` 下发**独立 CSP**：
  `script-src 'self' 'wasm-unsafe-eval'`、`connect-src 'self'`、`worker-src 'none'`、
  无 `unsafe-eval`、无外链；`X-Frame-Options: DENY`。
- 主站默认 CSP 保持 `script-src 'self'`，不含 `wasm-unsafe-eval`；课堂交互沙箱
  `worker-src 'none'` 不放宽。
- 页面：左侧代码编辑器、右侧输出、运行/清空、Ctrl/Cmd+Enter；首次运行按需注入
  同源 `pyodide.js` 并 `loadPyodide({indexURL:'/static/vendor/pyodide/'})`，
  30s 加载超时与中文错误；输出/异常一律 `textContent`，不拼 HTML。
- 页面不写入主站 SPA 导航；独立路由可直接访问（登录后）。

## 3. 验证

- `tests/test_pyodide_lab.py`：6 个资产的尺寸/SHA/README、专用页 CSP 与页面结构、
  主站 CSP 未被放宽、未登录 401、静态资产可达、脚本接线与无 eval/new Function。
- 浏览器（Edge headless，真实服务端）：登录后打开 `/lab/python`，点击运行，
  输出 `你好，知序`、`1..25` 平方与 `5050`；**零 `securitypolicyviolation`**、
  零页面 error。
- 验证环境实测：核心 11.9MB，专用 CSP 下加载 972ms，`1+1` 4ms；主站 CSP 下
  12s 内无法完成加载（因此不接入主站）。
- 全量回归：**2167 passed, 5 skipped, 4 warnings in 1039.58s（17:19，exit 0）**，
  详见 `验收记录.md` 进阶项章节。
