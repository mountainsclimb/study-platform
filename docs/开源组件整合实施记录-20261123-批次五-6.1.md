## 2. 预设 `web/vendor/geometry/geometryPresets.js`（自有代码）

- 十个预设：圆锥曲线统一定义、椭圆第一定义、双曲线第一定义、三角函数
  y=A sin(ωx+φ)、导数几何意义、线性规划可行域、二次函数系数、指数与对数、
  单位圆与正弦曲线、直线与圆位置关系；每题带 zh/en 标题与板上文案。
- **纪律（静态检查 + 浏览器运行时双重验证）**：
  - 所有函数与坐标写成 JS 数值/函数入参，**不出现字符串形式的数学表达式**
    （`tests/test_oss_vendor_assets.py::test_geometry_presets_discipline` 剥离注释后
    断言无 `Math.random` / `new Function` / `eval` / 字符串表达式父项，并把文件复制为
    `.mjs` 用 node 做模块模式真解析——纯脚本模式会漏掉模板表达式语法错误，本轮实测踩过）；
  - 浏览器侧把 `Math.random` 按**调用栈区分**替换：预设代码命中即抛错（实测零命中），
    JSXGraph 库内部（曲线不连续处的自适应采样抖动）放行；
  - 动态元素全部用函数父项声明，滑杆拖动后整板自动重算。
- `findGeometryPreset(id)`、`normalizeGeometryParams(preset, raw)`：参数逐项收敛到
  预设声明的范围，非法回退默认值。

## 3. 组件 `web/js/components/geometryDemo.js`

- `normalizeGeometryDefinition(raw)`：预设不存在返回 null；data 轻参数
  `{preset_id, params}`。
- `loadJsxGraph()`：懒注入（脚本 + 样式 link），失败可重试，全局 `JXG`。
- `createGeometryView(container, definition, {readOnly})`：
  - 可编辑模式按预设声明挂板内滑杆，参数对象用 **getter 读滑杆实值**，
    保存时 `getParams()` 拿到拖动后的值；只读模式不挂滑杆，按保存值静态重建；
  - `pngURI()` 异步返回 SVG→PNG 海报（内联 SVG 无外链，CSP `img-src data:` 允许）；
  - 失败中文降级 + `console.warn` 记录细节；`destroy()` 经 `freeBoard` 释放，
    幂等；ready 回调由调用方按控制器 token 判定（对齐 §6.3 修复口径）。
- `openGeometryDemo(options)`：原生 `<dialog>`，预设下拉、重置、保存为
  `geometry_demo` 学习附件（PNG ≤60KB 附带）；标题兜底本地化。

## 6. 审查修复（2026-11-23，code-reviewer 结论：2 HIGH + MEDIUM 若干，HIGH 全部修复复验）

- **H1 线性规划预设的字符串文本**：`create('text', [x, y, 'x + y ≤ 6'])` 的字符串内容
  走 JessieCode 的 `board.jc.snippet → eval` 编译路径——首次验证时记录到的 14 次
  `script-src eval` 违规正源于此（该路径在部分浏览器上会级联成构建失败）。修复：
  文本内容一律函数入参（纪律测试新增静态断言，字符串文本被禁止）；加载成功后设
  `Options.jc.compile = false`（本组件不用 JessieCode，字符串内容走解释器）；
  vendor README 的 CSP 段同步更正。修复后实测 **CSP 违规 14 → 0**。
- **H2 海报裁切与文字丢失**：源 SVG 无 `viewBox`，固定设 640×380 会按新视口裁掉
  右端；文本默认渲染为 SVG 外的 HTML 覆盖层，序列化海报丢全部标签。修复：
  `svgToPngURI` 按源 SVG 真实宽高补 `viewBox` 并等比缩放（实测 720×380 → 640×338）；
  加载后设 `Options.text.display = 'internal'`，标签/读数/滑杆文字进 SVG（实测
  单板 SVG `<text>` 23 个，33KB 海报完整）。
- **M1 失败路径**：`rebuild` 在 ready 失败时禁用保存按钮（成功恢复）；`save()` 以
  `getDefinition()` 非空为准入，失败/非法视图不再保存出无海报默认参数的空附件；
  构建中途异常时 `freeBoard` 释放半初始化板；失败文案按阶段区分——库加载失败报
  「加载失败」（`unavailable`），建板/预设构建失败报「构建失败」（新增
  `study.oss.geometry.buildFailed` 键）。
- **M2 参数类型严格化**：`normalizeGeometryParams` 仅接受真数值或可完整解析的非空
  数值字符串；`null`/空串/数组/布尔回退预设默认值，不再被裸 `Number()` 隐式转成
  0/1 后收敛到 min（Node 单测覆盖全部边界）。
- **M3 二次函数 a≈0**：`|a|<0.05` 时隐藏顶点与对称轴，读数切换为「a ≈ 0：图像是
  一次函数（直线），无顶点与对称轴」，不再显示 (20, −19) 这类伪造顶点。
- **M4 测试缺口**：纪律断言补「text 字符串内容」规则（实测能咬住旧写法）；几何
  导出用例补 `data:image/png;base64,` 海报断言；新增 Node 驱动的纯函数单测
  （`test_geometry_preset_normalizers_via_node`）。课堂插入端不加 geometry 结构
  422（审查判定非阻断：渲染端 `normalizeGeometryDefinition` 拒绝未知预设、参数
  只取有限数值、导出 JSON 已转义，无安全缺口）。
