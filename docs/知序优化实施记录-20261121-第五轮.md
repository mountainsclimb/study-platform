## 2. 共用数据层

### 2.1 学习证据 `app/study_evidence.py`（表 `study_evidence`）

- **单一事件表 + 版本行**：一次有效证据一行；重判不新增有效证据，而是写入新版本行（`event_key=<基础键>#v<n>`）
  并把旧行标 `valid=0`、`superseded_by=新行 id`。对外读取只看 `valid=1`，修订/查询统一传基础键。
- **幂等**：`UNIQUE(user_id, event_key)` + `INSERT ... ON CONFLICT DO NOTHING`，并发/重复调用只留一行；
  `con=` 传入时不在内部 commit/begin，由调用方事务决定可见性（外层回滚则证据一并回滚，已测）。
- **公开函数**：`record_event`、`record_attempt_evidence`、`attempt_event_key`、`revise_event`、
  `revise_attempt_evidence`、`active_event`、`question_evidence`、`summary`。
- **口径**：`verdict`（correct/incorrect/pending/unknown）、`grade_source`（reference/ai_cross_verified/manual/pending/self）、
  `confidence`（verified/pending/unknown）、`prompt_state`（none/hint/step/unknown）、`reveal_state`（before/after/unknown）、
  `self_report`（none/independent/assisted/unknown）。旧判分缺少提示/揭晓信息时一律 `unknown`，不猜测；
  学生自评是独立事件（`kind=self_report`），**不覆盖**核验结果；`sample_sufficient` 以「≥2 次独立且已核验」为界，
  不足时返回「样本不足」而非给结论。
- **路由**：`GET /api/evidence/summary?days=90`、`GET /api/evidence/question/{ref:path}`（非法引用 422，不回显题干/答案）、
  `POST /api/evidence/self-report`。

### 2.2 学习附件 `app/study_artifact.py`（3 张表）

- `study_artifacts`（元数据/当前版本/软删）、`study_artifact_revisions`（不可变内容 + checksum）、
  `study_artifact_links`（挂到 `question|note|classroom|review|assistant`）。
- **kind**：`function_graph|whiteboard|reading_excerpt|flow_animation|isometric|science_demo|demo_3d`。
- **版本语义**：新增内容一律新 revision（`expected_revision` 不符 → 409）；仅改标题不升版；
  链接 `revision=NULL` 表示跟随最新（个人笔记），整数表示固定版本（课堂发布/导出）；软删后读取/列表/按目标均 404，
  历史与链接保留在库内供备份/审计。
- **限额**：data ≤ 256 KiB（413）、preview ≤ 64 KiB（413）、title ≤ 120、单附件 links ≤ 20、kind/target_kind 白名单（422）。
- **授权**：所有读写按本人 `user_id`；他人或不存在统一 404「附件不存在或无权访问」，不泄露存在性。
- **路由**：`/api/artifacts`、`/by-target`、`/{id}`（GET/PATCH/DELETE）、`/{id}/revisions`、`/{id}/links`（POST/DELETE）。

### 2.3 四档复习卡 `app/study_review.py`（2 张表）

- `review_cards`（每用户每卡面键一行；`card_key="q:"+storage_key`；到期时间、状态 JSON、版本号、归档标记）、
  `review_ratings`（一次明确评分一行，幂等键唯一；含评分前后状态、服务端到期、算法/版本）。
- **算法**：`fsrs-reference` / `5.0-local` = FSRS-5 公开默认 19 权重 + 保留率 0.9 的本地参考实现（确定性、日粒度、
  间隔夹在 1–36500 天）；`STUDY_REVIEW_CLOCK` 固定服务端时钟（测试/验收）；`STUDY_REVIEW_ENGINE=ts-fsrs|external`
  时调用 `_external_schedule` 适配位——当前环境无 Node 引擎，捕获 `ReviewEngineUnavailable` 后**降级 200**：
  不改变到期与状态、不写评分行、返回「已保留最近一次有效到期时间，稍后重试」+ `retry_allowed=true`，
  恢复后用同一幂等键重试只应用一次。
- **迁移**：`sync_wrong_question`/`sync_user_cards` 只读 `wrong_questions`：无卡则按旧 `next_review_at` 建 `new` 卡；
  已有卡只同步归档标记，**绝不覆盖真实排程状态**；幂等可重复。作答判分后由 `app/practice.py` 同事务调用。
- **评分**：`rating∈1..4`，`card_version` CAS（409）、`idempotency_key` 重放（`replayed=true`，不重复推进）。
- **对账**：`compare_due` 输出 `checked/matched/mismatched(diff_hours)/missing_cards/extra_cards`，供切换读路径前的证据。
- **路由**：`GET /api/review-cards/{due,compare,stats}`、`POST /api/review-cards/sync`、
  `GET /api/review-cards/{id}`、`POST /api/review-cards/{id}/ratings`。

### 2.4 OCR 内容块（`app/ai/ocr.py`、`app/ai/upload_pipeline.py`）

- 每个块：`{id,kind,text,latex,needs_review,confidence,bbox{px},norm{0-1},page,order,rotation,source,engine,engine_version}`；
  一行一块、阅读顺序按视觉行 top 聚类后行内 x 排序。**本地引擎不做公式识别**：`kind=math` 时 `latex=null`、
  `needs_review=true`，`capabilities.math_recognition=false`；Pix2Text 只保留适配位，未安装。
- 兼容性：`recognize_image`/`recognize_pdf_pages` 默认返回结构不变（新字段需 `include_blocks=True`）；
  `POST /api/ai/ocr`、`ocr-draft`、`engine_status()/info` 追加字段；旧响应字段全部保留。
- `PATCH /api/uploads/{id}/confirm` 新增可选 `blocks`（≤200）：传了才覆盖，未传沿用 draft/confirmed；base 无 blocks
  时不追加空键；非法块 422 中文。异步识别在人工确认后只写 `pending_draft_json`（既有版本保护 + 块）。

## 6. 风险与注意

1. **对账口径**：评分之后新卡到期会前推，`compare_due` 在评分后出现 `mismatched` 属预期；切换读路径前应在
   「未评分/刚迁移」状态对账，并记录差异原因。
2. **算法版本**：本地参考实现与官方 ts-fsrs 参数可能随版本演进；算法标识已随卡状态与评分日志落库
   （`fsrs-reference` / `5.0-local`），升级需写迁移映射，不能直接改权重重算历史。
3. **公式能力**：`kind=math` 是启发式判定，`latex=null` 表示未识别而非空；界面必须保留人工校对，
   不得把 `needs_review=false` 当作机器已识别公式（用户手填后才会置 false）。
4. **附件体积**：data ≤ 256 KiB 对白板/图形元素数量有约束，前端需控制点/元素规模；超限返回 413 中文提示。
5. **事件键口径**：`record_kind` 白名单为 `attempts/pl_paper_attempts/paper_scan/cls_quiz_attempts/review_cards/self`；
   答题卡记录用 `paper_scan` + 扫描记录 id（表名 `pl_card_scans`），不要新增未登记的表名。
6. **两处兜底建表**：课堂/工坊接线在启动钩子缺失时会在写事务外幂等补建证据表（仅首次），
   若确认启动顺序稳定可删除，逻辑不变。
