## 明细

### 1. RDKit（GO）

- 验证环境：`E:\responsibility\.vendor-src\adv-venv`（Python 3.11，独立 venv）。
- 安装：`rdkit==2025.3.5` wheel 23.5MB，附带 numpy 2.4.6（12.6MB）、Pillow 13.0
  （7.3MB）；venv `site-packages` 合计 144.3MB。
- 实测：`from rdkit import Chem` + Descriptors 0.195s；`CCO` → `C2H6O / 46.069`，
  `c1ccccc1` → `C6H6 / 78.114`，布洛芬 SMILES → `C13H18O2 / 206.285`；
  `INVALID(` 被拒绝。
- 风险：可选安装会把 numpy/Pillow 拉高（本项目生产锁定 Pillow 12.2），需在
  `requirements-chem.txt` 中锁版本并验证共存；只应作为服务端可选依赖，不进前端。
- 建议落点：`POST /api/chem/info`（SMILES 校验/规范 SMILES/分子式/摩尔质量），
  分子查看器展示分子式与分子量；未安装 rdkit 时 503，不影响 `/api/chem/balance`。

### 2. Pyodide（条件 GO）

- 资产：0.28.0 的 `pyodide.js` 17KB、`pyodide.asm.js` 1.1MB、
  `pyodide.asm.wasm` 8.3MB、`python_stdlib.zip` 2.4MB、`pyodide-lock.json` 107KB，
  核心合计约 **11.9MB**（未计按需包）。
- 实测（Edge headless，本地 HTTP）：专用策略
  `script-src 'self' 'wasm-unsafe-eval'` 下加载 972ms，`1+1` 运行 4ms，版本 0.28.0。
- 主站策略（`script-src 'self'`，无 `wasm-unsafe-eval`）：12s 内未完成
  `loadPyodide`（Promise 未 settle）；即便 `WebAssembly.compile` 可执行，也不可
  在主站/课堂交互沙箱内使用。
- 建议：仅在独立策略的专用页（`wasm-unsafe-eval`，仍 `worker-src 'none'`）按需
  懒加载；课堂 `interactive` 沙箱不放宽。首载 11.9MB 需进度提示与缓存策略。

### 3. latex2sympy2（暂缓）

- 包：1.9.1（97KB wheel），依赖 `sympy>=1.4` 与 `antlr4-python3-runtime==4.7.2`。
- 依赖问题：antlr 4.7.2 只有 sdist，pip 24 + Python 3.11 元数据构建失败；
  本次改为下载 sdist 后手工拷贝 `antlr4` 包才可导入。落地前必须解决可复现安装
  （自建 wheel / 固定旧 pip / vendored runtime）。
- 数据：`eval/golden-v2.jsonl` 的 `content_refs` 只有 text(762) 与 image(116)，
  **没有 latex/formula 层**，无法按方案做“公式层等价判定”回归。
- 题库抽样（bank-20261121-r5）：全库唯一 LaTeX 201,970 条（非平凡 197,816）；
  纯表达式过滤后取 1200 条，latex2sympy2 成功 706 条（**58.8%**，10.3s）；
  未过滤的混合公式 800 条成功率 16.5%。失败集中在 `\sqrt2` 无花括号、区间/不等式、
  `\cdots`/关系符与部分符号。
- 建议：先补 golden 公式层与 LaTeX 预处理/白名单，再评估接入
  `app/ai/verify.py` 的 `_parse_expression()`；当前不接入。

### 4. FSRS 参数标定（暂缓）

- 方案前置：单用户 1000 条以上评分记录；现有 `review_ratings` 仅供幂等重放读取，
  没有导出。
- 实测本地 `data/app.sqlite3`：`review_ratings` **0 行**、`review_cards` 0 行，
  远低于门槛。
- 建议：先实现评分日志导出与数据积累；达到门槛后再决定“补参数入口”或“迁移到
  fsrs 6.x 库 + 旧实现回退”。

### 5. Ketcher（暂缓）

- `ketcher-standalone@3.21.0`：解包 111MB，Apache-2.0；需要自托管构建、iframe
  独立策略与既有交互沙箱的隔离审计。
- 当前题目表单/题库没有“结构式字段”的产品需求；先记录，等需求明确再按 1.5 人日验证。

### 6. MapLibre GL JS（暂不实施）

- `maplibre-gl@6.19.0`：解包 30MB，BSD-3-Clause；需要底图瓦片来源、Worker/WebGL
  策略与境内公开地图审图合规结论。
- 方案已给出更轻的中间选项（原生 SVG 专题图/Leaflet）；建议先用 SVG，确有缩放与
  底图需求再立项。

### 7. pyKT（另立项）

- 依赖 torch 与独立训练环境；本机虽可 import torch，但没有训练数据、训练脚本与
  推理服务边界。主工程只应消费“知识点掌握概率”文件，不在本次批次内。
