# 阶段四实施记录：语音贯通（2026-11-24）

对应《项目现状审查与功能联合整合赋能方案》阶段 4（4-1 ~ 4-5）。本轮把课堂命名空间里的
语音能力抽成跨场景接口，接入题目/笔记/词汇/跟读，并让本地合成音频经过压缩；不改变
课堂旧接口语义，不把「假引擎通过」当作真实模型可用。

## 1. 交付范围

### 4-1 通用朗读接口（`app/speech_api.py`）

| 方法/路径 | 说明 |
| --- | --- |
| `GET /api/speech/info` | 合成/识别能力、来源（local/provider）、模型、上限、压缩格式与中文说明；不加载模型、不回密钥与目录。 |
| `POST /api/speech/tts` | 文本 → 音频字节；本地或已配置云端 TTS；`X-Speech-Source/Format/Voice/Elapsed-Ms`；无服务端合成 503。 |
| `POST /api/speech/transcribe` | 本地 ASR 优先，其次已配置云端 ASR；不保存录音。 |
| `POST /api/speech/shadowing/check` | 跟读转写 + 文本相似度；明确「不代表发音质量」。 |

- 连接选择与音色规范化复用 `app/classroom/tts.py`（新增 `select_candidate`、
  `synthesize_provider`），新旧路径对同一文本/音色走同一个厂商请求函数。
- 课堂 `POST /api/classroom/tts` 与 `/api/classroom/asr` 保持兼容并继续服务课堂页面。
- 本地短文本进程内 LRU（≤16 条，键含文本/音色/速度/模型/目标格式），长文本不缓存。

### 4-2 多场景朗读（`web/js/components/readAloud.js`）

- 统一「朗读/停止」按钮：先 `POST /api/speech/tts`，503/网络失败回退浏览器
  `speechSynthesis`；都不支持时明确提示不可用。
- 长文本按标点切分为 ≤600 字分段，逐段合成/播放；`hashchange` 与换题/重渲染时停止并
  释放 Blob URL。
- 接入：题目题干+选项（`questionSpeechText`）、答案/解析展开面板、笔记标题+正文、
  词汇 due 卡与词表行。Markdown/LaTeX 标记在 `plainTextForSpeech` 中去噪。

### 4-3 跟读检查（`web/js/components/shadowingCheck.js`）

- 录音（MediaRecorder）→ `blobToWav16k` → `POST /api/speech/shadowing/check`；
  显示文本相似度、识别文本、原文与「不是发音评测」说明。
- 题目页「跟读检查」按需展开；词汇卡可按单词展开；收起/换题/路由切换时销毁录音。
- 识别不可用时只显示原文与不可用原因，不产生分数。

### 4-4 合成音频压缩（`app/ai/audio_compress.py`）

- 本地 TTS 的 WAV 在落库/返回前转 MP3（默认 64k）或 Opus（32k）；
  `STUDY_TTS_FORMAT=mp3|opus|wav`、`STUDY_FFMPEG` 可配；ffmpeg 缺失/失败/超时回退 WAV。
- 课堂本地旁白落 `cls_assets` 前压缩，内容寻址缓存键天然包含格式与音色；通用朗读与
  词汇听写单词音频复用同一函数。
- 实测（本机 ffmpeg 9.0.2，48,044 字节 1 秒 24k WAV）：MP3 8,492 字节（17.7%）、
  Opus 5,040 字节（10.5%），输出头分别为 `ID3` / `OggS`。

### 4-5 听写收口与真实模型 smoke

- 词汇听写改用 `app.ai.speech_score` 的编辑距离评分（与跟读共用规范化口径）；
  单词音频经 `audio_compress` 压缩，`next` 返回 `audio_mime`，数据 URI 使用真实 MIME。
- `tests/test_speech_real_models.py`：仅在 `STUDY_LOCAL_SPEECH=on` 且 TTS/ASR 模型可用时
  执行「TTS→ASR 往返」与 WAV 头检查；本机未预置模型，2 条按设计 skip。

## 3. 安全与隐私边界

- 四个端点均要求登录；未登录 401。
- 朗读文本不落库、不写学习证据；跟读/转写音频只在请求内处理，不保存。
- 响应头只回源/格式/耗时，不回密钥、宿主机目录或中文厂商名（避免 header 编码问题）。
- ffmpeg 调用固定参数、无 shell，超时 30 秒；失败不阻断主流程。
