## 2. 逐步提示 `app/guided_hint.py`（表 `guided_hints/guided_steps/guided_attempts`）

- **规则生成**（明确标注非 AI，完整解析仅在尝试后解锁）：
  1. `focus`「审题：题目到底在问什么」= 题干前 300 字 + 审题指令，含 `requires_attempt=0`，创建即解锁；
  2. `concept`「相关知识点」= `question_kp JOIN knowledge_points` 最多 5 个；无关联时显示「样本不足」文案；
  3. `first_step`「第一步思路（来自原题解析首步）」= 剔除答案行后的解析首 1–2 句（≤300 字），并注明来源；
  4. `solution`「完整解析与参考答案」= 解析全文 + 参考答案，始终锁定至前面步骤均有尝试。
  无解析题目退化为 3 步（含「题库未附解析」兜底），`total` 如实。
- **解锁协议**：`advance` 仅当末尾已解锁步骤存在尝试记录时解锁下一步（最多一个）；没有尝试 → `requires_attempt=true` + 中文提示且幂等；全部解锁 → `status=completed`。
- **不泄露**：锁定步骤视图只有 `{position,kind,title,locked:true,requires_attempt:true}`，测试递归断言任何响应（create/get/by-ref/list/advance/attempt）都不含锁定正文。
- 尝试记录 `(hint_id,position)` 唯一、1–2000 字、重复提交 `replayed`；跨用户 404；`practice_allowed=false`/隔离题 409。
- `source_note` 明示：「基于原题题面与解析的规则分步提示（本轮未接 AI 生成）；完整解析仅在提交尝试后解锁」。AI 生成版本列为后续增强，不在本轮声称。

## 3. 资料原文定位与摘录 `app/doc_location.py`（表 `doc_annotations`）

- **版本口径**：不新增版本列，`doc_version = sha256(json.dumps(chunks, ensure_ascii=False, sort_keys=True))[:16]`（内容摘要即版本，读时计算）。
- **定位**：`POST /api/documents/{id}/locate` 支持 `chunk_id` 精确 → `quote`（空白折叠 + ASCII 大小写归一，返回原始文本偏移与命中方式 exact/normalized）→ `page`；返回 `{page,chunk_id,heading_path,quote,snippet,start,end,match,doc_version}`；找不到 422，跨账号 404。
- **摘录**：`POST /api/doc-annotations` 保存 quote + 版本 + 位置快照；`GET` 列表实时校验（资料仍在本人名下、版本一致、quote 仍可定位），失效条目不 500 并给出中文 `invalid_reason`；`POST /{id}/refresh` 在新版本重新定位（`migrated`），找不到仍 200 + 失效原因；`DELETE` 本人限定。
- 上限：quote ≤500 字、note ≤1000、单文档 ≤200 条、颜色白名单；详情见 API 索引 §26。

## 4. 掌握路径 `app/mastery_path.py`（表 `mastery_paths/mastery_path_nodes/mastery_path_events`）

- **大纲**：每个知识点 2 个节点——`practice`「独立答对 2 道不同题」→ `concept`「用自己的话复述并说明一道例题」；自动选薄弱（有已判定证据且正确率 <70%）最多 3 个，或调用方显式指定 `kp_ids`（≤8）；相同知识点集合的 active 路径幂等复用（`replayed`）。
- **完成条件（只来自明确学习证据）**：
  - `practice`：该知识点关联题中至少 **2 道不同题**满足 `study_evidence` 有效、已核验、`verdict=correct` 且独立（`self_report=independent` 或 `prompt_state=none`）；提示/揭晓后作答不计；同一题重复正确只算 1 道。`refresh` 返回 `{distinct_questions, matched_questions, missing, note}`，不足保持 pending。
  - `concept`：学生提交 20–2000 字复述，记为 `self_report=independent` 的独立自评，不冒充核验结果。
- **样本不足**：知识点关联题 <2 时 `sample_status=insufficient` 并给中文说明，不伪造完成；自动选择在无任何证据时 422「样本不足，无法自动生成掌握路径；请显式指定知识点」。
- **状态/版本**：节点 `pending/in_progress/done`，路径 `active/completed/archived`；每次重算 `version+1`；证据被修订后刷新会回退重开并记事件；归档幂等。
- **练习证据口径修正**：`app/practice.py::_record_study_evidence` 对普通练习/作答记录 `prompt_state="none"`（该入口不提供分步提示，答案在提交后判分），使「练习节点」在真实刷题后能被核验；AI 复核只升版同一事件、不改提示/揭晓状态。

## 5. 数学组件（§5.4，原生实现 + Mafs/Excalidraw 兼容数据模型）

- **函数图** `web/js/components/functionGraph.js`
  - 定义：`{version,source:'mafs-compatible',expressions:[{latex,color,visible}],params:[{name,value,min,max,step}],xRange,yRange,points,labels}`，保存为 `function_graph` 附件。
  - 安全性：自写 tokenize→递归下降 AST→求值（+ - * / ^、括号、sin/cos/tan/sqrt/abs/exp/ln/log、pi/e、参数与 x），**不使用 eval/Function**；非法表达式中文报错且不绘制错误曲线；`^` 右结合、一元负号正确。
  - 交互：参数滑块实时重绘、二次函数顶点标注、SVG 坐标轴/刻度/网格、深色主题、触屏可用；弹层 `openFunctionGraphForTarget` 打开时按 `by-target` 读取已保存版本（4s 超时降级为预设/题目 `study.artifacts`）。
- **白板** `web/js/components/sketchBoard.js`
  - 场景：`{version,source:'excalidraw-compatible',appState,elements:[{type:freedraw|line|arrow|rect|ellipse|text|formula,...}]}`，line/arrow 用 `points`（与 Excalidraw 同构），保存为 `whiteboard` 附件。
  - 能力：7 类元素、颜色/线宽、撤销/重做（≤50）、选择/删除/清空、文字与 KaTeX 公式（`renderMath` 净化）、导出 PNG、预览自适应压缩 ≤64KiB（超限省略预览但保存成功）、元素 ≤300、序列化 ≤256KiB 中文提示。
- **附件与跨页复用**：保存/另存新版本走 `/api/artifacts`（`expected_revision` 冲突 409 中文）；题目与错题页通过 `by-target` 重开同一版本；课堂/笔记打开同一附件留待 M4 接线（本轮先保证题目与错题可复用）。
- **页面接线**：`question.js` 增加「函数图像」（数学/含公式题）、「画解题思路」（所有题）、「按步骤提示」（所有题）三个入口，组件按需动态 import；`wrongbook.js` 每行「解题工具」菜单复用同组件，非数学题「看图」给中文提示。
- **逐步提示面板**：题目页内直接调用 `/api/guided-hints`（先 `by-ref` 再回退创建），显示已解锁步骤，提交尝试后 `advance` 逐级解锁，完成态显示 `source_note`；接口不可用只影响该功能。
