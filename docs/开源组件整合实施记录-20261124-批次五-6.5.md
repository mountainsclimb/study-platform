# 开源组件整合实施记录（2026-11-24，批次五 §6.5：vis-timeline 历史时间轴）

对应方案：`../docs/开源组件整合实施方案-通用版.md` §6.5。前置提交：批次五 §6.4（markmap 交互脑图）。
本轮交付新的学习附件类型 `timeline`，以及历史/政治题的「时间轴」入口。

## 1. 构建产物与脚本

- `web/vendor/vis-timeline/`：直接引用 npm 包 `vis-timeline@8.5.6` 的 standalone 产物，
  未做任何改动：
  - `vis-timeline-graph2d.min.js`（528,740 字节，SHA-256 `01e838f3…a25889`）；
  - `vis-timeline-graph2d.min.css`（19,780 字节，SHA-256 `43689b3d…dde5a8a`）；
  - `LICENSE.Apache-2.0.txt`、`LICENSE.MIT.txt`（双许可，本仓库按 MIT 使用）；
  - `README.md`（版本、大小、SHA-256、CSP 与数据安全说明）。
- standalone 产物内含 `moment` 与 `vis-data`，无 `new Function` / `eval(`（测试静态断言）；
  不随仓库分发 `esnext/`、`declarations/`、`types/`、`peer/` 与 `.map`。
- 与 §6.4 不同，本组件不需要一次性打包：npm 包自带 UMD 单文件，主站直接同源懒加载。

## 2. 预设与数据规范化（`web/vendor/timeline/timelinePresets.js`）

- 四个专题预设，共 71 条人工校对的事件：
  - 中国近代史（1840–1949，21 条）；
  - 世界近现代史（1492–1945，17 条）；
  - 新中国史（1949–2021，15 条）；
  - 科技史里程碑（1543–2003，18 条）。
- 日期一律为 `YYYY` / `YYYY-MM` / `YYYY-MM-DD`（公元 1–9999 年，四位年份），
  校验含月份天数与闰年；不收录公元前日期，避免各引擎的纪年显示差异。
- 事件标题为人工校对的中文史实条目（与教材/通行年表一致），分组名随界面语言
  切换中英文；每个预设的 `source` 字段记录校对依据。
- 事件按开始日期稳定排序；`normalizeTimelineDefinition()` 拒绝未知专题、非法日期、
  结束早于开始、事件数不在 1–200、非法选项（高度 280–720、缩放范围正整数）。
- `escapeTimelineHtml()` 在数据进入 vis-timeline 前转义 `& < > " '`，事件标题按纯文本渲染。
- 不使用 `Math.random`；预设只依赖数据，保存后可完全重建。

## 3. 接入点（`web/js/components/timelineDemo.js`）

- `loadVisTimeline()`：懒注入 `/static/vendor/vis-timeline/vis-timeline-graph2d.min.js`
  与样式（UMD 全局 `vis`），15s 超时、失败可重试、中文降级。
- `createTimelineView(container, definition, {readOnly})`：
  - 事件 → `vis.DataSet`，分组按预设顺序生成（`_default` 兜底）；
  - 中英文刻度文案（年/月/日），关闭选择与编辑，保留缩放与拖动时间窗；
  - 返回 `{element, ready, getDefinition, pngURI, destroy}`；`destroy()` 调
    `timeline.destroy()` 并移除宿主。
- `pngURI()`：不截页面 DOM，按事件时间范围与分组用 Canvas 2D 画 640×360 海报
  （白底、年份刻度、分组泳道、事件点/区间），确定性、无外部依赖；实测约 36KB。
- `openTimelineDemo()`：弹层内切换专题、填写标题/开始/结束/分组自建事件（可删除）、
  实时重建；保存为 `timeline` 学习附件（`POST /api/artifacts`），只读模式禁用编辑与保存。
