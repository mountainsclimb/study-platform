# 开源组件整合实施记录（2026-11-24，§9 进阶项：RDKit 化学信息）

RDKit 为唯一明确 GO 的项，本记录为验证通过后的最小落点。

---

## 1. 依赖与边界

- `requirements-chem.txt`：`rdkit==2025.3.5`（BSD-3-Clause，wheel 约 23.5MB），
  `numpy>=1.26.4,<3`、`Pillow>=12.2.0,<13`（只圈定兼容范围，不强制降级主环境）。
- 仅服务端可选依赖：不 vendor、不进前端、不进生产镜像；未安装时
  `/api/chem/info` 返回 503，既有 `/api/chem/balance` 与 OpenChemLib/3Dmol 渲染链路不变。
- 实测环境：numpy 1.26.4 + Pillow 12.2.0 与 numpy 2.4.6 + Pillow 13.0.0
  均可解析；`from rdkit import Chem` + Descriptors 约 0.195s。

## 2. 后端（`app/chem_info.py`）

- `POST /api/chem/info`（登录）：`{"smiles": "..."}` → 
  `{"ok": true, "canonical_smiles", "formula", "molecular_weight"}`；
  非法 SMILES 返回 200 + `ok:false` + 中文 `reason`；RDKit 未安装返回 503。
- `analyze_smiles()` 惰性导入 RDKit、关闭 rdApp 日志；空串/超 500 字符/解析失败/计算失败
  均返回 `ok:false`，不抛未处理异常。
- 注册进 `app/main.py` 的路由列表（与 `/api/chem/balance` 同前缀）。

## 3. 前端（`moleculeViewer.js`）

- 分子渲染成功后异步请求 `/chem/info`，在画布下方显示
  「分子式 C2H6O · 相对分子质量 46.069」；接口 503/失败时静默隐藏，不影响 3D 预览。
- 文案键 `study.oss.molecule.info`（zh/en 成对）；`.oss-molecule-info` 样式。
