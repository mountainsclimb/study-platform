## 1. 适配模块 `app/ai/speech_local.py`

- 可选依赖 `sherpa-onnx==2.0.3`（Apache-2.0），新清单 `requirements-speech.txt`；
  Python 3.11 Windows 轮子已安装验证，模块导入与假引擎测试通过。
- 两个延迟单例引擎：
  - 合成：Kokoro `kokoro-multi-lang-v1_1`（`model.onnx`、`voices.bin`、`tokens.txt`、
    `espeak-ng-data/`、`lexicon-us-en.txt`、`lexicon-zh.txt`）；
  - 识别：Paraformer-zh（`model.onnx`、`tokens.txt`），`from_paraformer(...)`。
- 开关与环境：
  - `STUDY_LOCAL_SPEECH=on`（默认 off）；
  - `STUDY_LOCAL_SPEECH_DIR`（默认 `<data>/models/speech`）；
  - `STUDY_LOCAL_TTS_MODEL` / `STUDY_LOCAL_ASR_MODEL`；
  - `STUDY_LOCAL_TTS_VOICE`（默认 `0`）、`STUDY_LOCAL_ASR_MAX_SECONDS`（默认 60，1–600）。
- 状态：`tts_available()` / `asr_available()` / `engine_status()`；目录与依赖缺失、
  初始化失败统一转 `SpeechUnavailable`，`reset_engine()` 可重试。
- 输入/输出口径：
  - `synthesize(text, voice, speed) -> (wav_bytes, "audio/wav")`，16-bit PCM 单声道；
  * `transcribe(wav_bytes) -> {"text", "words": []}`，只接受 16k 单声道 PCM16 WAV，
    超长拒绝，非 WAV 抛中文 `ValueError`（API 转 422）。
- 并发：`asyncio.to_thread` + 进程级信号量（2）；模型目录在调用时读取，兼容测试替换
  `db.DATA_DIR`。

## 2. 课堂旁白接入

- `app/classroom/tts.py`
  - `tts_provider_info()`：无厂商候选且本地合成可用时返回 `provider: "local"`；
  - `list_voices()`：无候选时返回本地音色（`provider_id: null`、`source: "local"`）；
  - `synthesize()`：无候选时走 `_local_synthesize()`，合成结果仍经 `_save_audio_asset()`
    按内容哈希落 `cls_assets`，返回 `provider: "local"`；失败回退 `{"fallback":"browser"}`
    并带中文错误；
  - `normalize_voice_for()`：本地 provider 使用音色序号。
- `app/classroom/narration.py`
  - `_resolve_tts_candidate()`：无厂商候选且本地可用时返回 provider_id 为 `0` 的内部哨兵
    （`kind: "local"`、`model: "local:..."`），不再 422；任务体/断点续跑不变。
- `app/ai/jobs.py` / `app/ai/providers.py`
  - `JobInput.provider_id` 仍是必填整数；本地哨兵使用 `0`，但 `submit_job` 限制
    `provider_id=0` 只允许 `course-narration`；
  - `_selected_provider(..., allow_local=True)` 仅在旁白路径返回合成 provider；其它路径
    仍走真实 `ai_providers` 归属校验。
- `app/classroom/api.py`
  - `GET /meta` 的 `tts` 与 `asr` 段在本地可用时为 local；
  - `GET /asr/info` 返回 `available: true, provider: "local", provider_id: null`；
  - `POST /asr` 在无厂商候选、未显式指定连接时走本地识别，返回
    `{"text", "model": "local:...", "usage": null, "filename"}`；非 WAV/超长 422。

## 3. 前端录音转换

- 新组件 `web/js/components/wavEncode.js`：`blobToWav16k(blob)` 用 WebAudio 解码
  MediaRecorder 的 webm/ogg/mp4，优先 `OfflineAudioContext` 重采样到 16k，回退线性
  重采样，输出 16-bit PCM 单声道 WAV。
- `web/js/components/voiceInput.js`：`asrInfo.provider === "local"` 时先转换再上传；
  服务端本地识别只收到 WAV。提示文案说明「录音只上传到本机知序服务」。

## 4.1 代码审查修正（2026-11-23）

- 本地旁白哨兵校验：`_resolve_tts_candidate()` 接受 `provider_id in (None, 0)` 且
  `model` 为空或等于本地模型标签的组合；`start_narration()` 转交 `JobInput(provider_id=0,
  model="local:...")` 时再次校验不再 422。显式厂商连接/模型仍保持原 422。
- ASR 选择器一致性：`/asr/info` 增加 `max_seconds`；`POST /asr` 接受
  `provider_id=0` 与 `model="local:..."`；`/classroom/voices?provider_id=0` 返回本地音色。
- 60 秒边界：`wavEncode.blobToWav16k(blob, {maxSeconds})` 在重采样后截断到服务端上限，
  `voiceInput` 读取 `/asr/info.max_seconds`；自动停止的录音不再因略超 60 秒被 422。

## 5. 未验证项与风险

- **真实模型未在本机下载**：Kokoro v1_1 约 365MB、Paraformer-zh 需另行下载；本轮只用
  假引擎验证接线。真实模型需按方案验收：零厂商建课→批量旁白→导出带音轨 MP4、20 条
  普通话/英语字错率记录、冷启动与常驻内存。
- 本地旁白 provider_id 用 `0` 作为内部哨兵，仅 `course-narration` 允许；这是对现有
  `JobInput.provider_id: int` 契约的最小改动，若后续把 JobInput 放宽为可空，可移除哨兵。
- 合成成功返回 WAV，`cls_assets` 的 `_MIME_BY_SUFFIX` 已支持 `wav`；前端播放器按浏览器
  能力播放 WAV。
- 模型权重许可按方案登记为 Apache-2.0（Kokoro / Paraformer-zh）；部署商业使用前仍需
  按各模型页复核。
