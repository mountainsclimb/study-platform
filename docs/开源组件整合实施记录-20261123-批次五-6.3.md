## 2. 组件 `web/js/components/physicsSandbox.js`

- `normalizeSandboxScene(raw)`：重力 `{x,y}`、刚体 `rect|circle|slope`、约束（弹簧）；
  刚体 ≤60、约束 ≤40；未知形状/超限/约束引用非法返回 null，数值字段非法回退默认值并
  收敛到安全范围；刚体显示名支持 `labelEn`（英文界面优先）。
- `createPhysicsSandbox(container, scene, {readOnly})`：
  - 懒加载 Matter.js；模拟固定在 640×380 设计坐标运行，视口只做渲染缩放
    （`Render` `hasBounds` + `lookAt`；鼠标经 `Mouse.setScale/setOffset` 换算回设计坐标），
    轨迹与读数和容器宽度逐位一致，Matter 的 slop/静止阈值等世界常量不受视口影响；
  - `Engine` + 自绘 `Render` + `Runner`，自动添加左右与底部边界；
  - `Render.create` 后探测 `render.context`，Canvas 2D 不可用同步拒绝（中文降级）；
    加载/运行失败与 `destroy()` 共用 `stopEngine()`（停 Runner/Render/Engine、移除画布，
    不留 rAF 异常循环）；`pause()` 在 Runner 启动前登记意图，启动后立即停转；
  - 可编辑模式挂 `MouseConstraint` 拖拽；只读模式不挂鼠标约束；
  - 返回 `{element, ready, getScene, readout, selectBody, pause, resume, pngURI, destroy}`；
  - `readout()` 返回观察对象的名称、位置与速度（设计坐标，速度为设计单位/秒，
    与容器宽度无关）。
- `openPhysicsSandbox(options)`：原生 `<dialog>`，预设（弹簧振子 / 斜面滑块 / 弹性碰撞）、
  观察对象下拉、播放/暂停/重置、保存为 `physics_sandbox` 学习附件（预览 PNG ≤60KB 时附带）。
- 确定性边界：页面固定显示「探索模式：Matter.js 的逐步积分不保证跨运行逐位一致……」；
  需要回放/对账的教学演示继续使用 physics-in-motion 确定性内核。

## 6. 审查修复（2026-11-23，code-reviewer 结论：0 CRITICAL / 3 HIGH / 6 MEDIUM）

提交前审查发现的问题与修复，全部完成并复验：

- **HIGH-1/2（视口相关性与读数口径）**：改为固定设计坐标世界（见 §2），640 与 900 宽
  容器停 rAF 手动推进 90 步后逐位一致（弹簧振子双方 `(320, 163.9)` 速度 0.81；
  斜面滑块双方 `(130.4, 319.7)` 速度 49.21）；读数去掉虚构的 `m/s` 单位，改口径为
  设计坐标 + 设计单位/秒，弹层/物理页/中英文案同步。
- **HIGH-3（Canvas 2D 缺席）**：`render.context` 探测 + 共用 `stopEngine()`；
  headless 实测 `getContext('2d')` 置空后 `ready` 为 `ok:false`、界面显示中文降级、
  600ms 内零未捕获异常。
- **MEDIUM-1**：弹层/物理页 `ready.then` 按控制器 token 判定，被重置/关闭取代或失败的
  结果不再把 `destroyed/invalid`/英文错误写进 UI。
- **MEDIUM-2**：`pause()` 登记意图，Runner 启动后立即停转；加载期间点暂停不再失效。
- **MEDIUM-3**：预设刚体增加 `labelEn`，英文界面下拉/读数/兜底标题全部本地化
  （新增 `study.oss.sandbox.bodyFallback` / `.custom` 键）。
- **MEDIUM-4**：物理页页签补 `role="tablist"/"tab"` + `aria-selected`（复用既有
  `[aria-selected="true"]` 样式）；读数 `aria-live` 从 250ms 降到 1s；页状态区补
  `role="status"`。
- **MEDIUM-5**：离线仅海报清单断言补齐；vendor 静态资源 GET 测试；课堂插入结构校验
  四种拒绝用例；浏览器拖拽实测（900px 画布把振子从 (320,190) 拖到 (461.2, 223)，
  `Mouse.setScale/setOffset` 换算正确）。
- **MEDIUM-6**：`schema.normalize_demo_content` 对 `physics_sandbox` 增加结构校验
  （`_validate_sandbox_demo_data`：刚体/约束上限、形状白名单、数值有限、约束索引范围，
  中文 422）；附件端仍仅限字节，文档口径对齐。NOTICES 版权行对齐 vendor LICENSE
  （Liam Brummitt and contributors）。

## 7. 边界与风险

- Matter.js 只用于探索模式，不承诺跨运行逐位一致；确定性教学演示未改动。
- 无 WebGL 不影响本组件（Canvas 2D）；Matter.js 加载失败或 Canvas 2D 不可用时中文降级。
- 场景数据只保存重力/刚体/约束参数，不序列化引擎对象；上限 60/40 由前端
  `normalizeSandboxScene` 与课堂插入时的结构校验共同限制（附件端仅限字节）。
