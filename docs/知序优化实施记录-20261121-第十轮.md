## 2. 专题报告 `app/topic_report.py`（表 `topic_reports`）

- 表：`(id,user_id,topic,title,generator DEFAULT 'rules',content_md,sources_json,status,version,created_at,updated_at)`；
  `init_topic_reports()` 幂等建表；写事务 `topic-report`；PG 兼容。
- `create_report(user_id, *, topic, document_ids?, note_ids?, kp_ids?, artifact_ids?, title?)`：
  四类来源至少一项（否则 422 中文）；每类 ≤10；个人报告 ≤50；归属校验（资料/笔记/附件本人，否则 404；知识点不存在 422）。
- `content_md` 固定七节（同输入同输出）：
  1. `# <title>` + 生成时间 + 「规则汇编，不含 AI 生成」；
  2. 一、主题与范围（来源计数/知识点/时间）；
  3. 二、资料依据：最多 2 段命中主题关键字的 chunk（未命中回退开头 2 段并注明），
     引用格式 `（来源：《标题》第 N 页 · chunk <id> · 文档版本 <doc_version>）`；
  4. 三、笔记摘录：笔记标题+前 200 字摘要 + 该笔记的摘录（doc_annotations，≤5 条，带出处）；
  5. 四、学习附件：标题/kind/固定版本 vN（不内联 base64）；
  6. 五、相关练习：题库检索候选（题干前 100 字 + 统一引用 + 来源标签），注明非正式标签；
  7. 六、学习证据 + 七、口径与局限（非 AI、引用随版本/删除失效、只摘录不改写）。
- `sources` 与正文一一对应（`document/note/annotation/artifact/question`，含 page/chunk_id/quote/version）。
- 路由：`POST /api/topic-reports`、`GET ""`、`GET /{id}`、`PATCH /{id}`（`expected_version` CAS 409）、
  `DELETE /{id}`、`GET /{id}/markdown`（text/markdown + RFC 5987 中文文件名）。

## 3. 互动讲义 `app/handout.py`（表 `handouts`）

- 表：`(id,user_id,title,course_id,note_ids_json,artifact_ids_json,question_refs_json,sections_json,
  generator DEFAULT 'rules',version,created_at,updated_at)`；`init_handouts()`；写事务 `handout`。
- `create_handout(user_id, *, title?, course_id?, note_ids?, artifact_ids?, kp_ids?)`：至少一项来源（422 中文）；
  归属校验（课程/笔记/附件本人，404；知识点 422）；个人讲义 ≤50；单类 ≤10。
- 小节（固定顺序）：`course_outline`（场景标题/类型/speech 摘要）、`artifact`（kind + 固定版本 + 来源 +
  合法 PNG 预览 data URI（累计 ≤300KB，超限省略并注明））、`excerpt`（笔记摘录 ≤10，带文档出处）、
  `practice`（题库候选，注明非正式标签）、`evidence`（学习证据真实字段 + 样本是否充足）、`meta`（规则汇编声明/引用局限）。
- 导出：`GET /api/handouts/{id}/export?format=html|pdf`（默认 html）：自包含 HTML（内联 CSS、无脚本无外链、
  `html.escape` 全转义、`data-handout-id`/`data-version` 固定版本标记）；PDF 用既有
  `app.ai.render.html_to_pdf`（Playwright），依赖不可用 503 中文降级；非法 format 422。

## 4. 小纸逐步提示工具（`app/assistant.py`）

- 新增只读工具 `step_hint`（`side_effect=false`、`requires_confirmation=false`，参数 `ref`）：
  读取 `guided_hint.get_hint_by_ref`，无会话时幂等创建；只回传公开视图（`hint`+`steps`），**锁定步骤服务端本就无正文**，
  工具不补全/不推测；摘要中文「第 x/N 步已解锁；后续步骤需先在题目页提交尝试后才会解锁」，`refs` 指向题目统一引用。
- 系统提示新增规则：只引用已解锁步骤，不得编造锁定内容，完整解析须提示学生到题目页逐级提交尝试。
- 工具清单（`/api/assistant/tools`）由 13 增至 14 个。

## 5. 扫描资料本地识别扩面（`app/ai/notes_agent.py`）

- 新增 `_normalize_ocr_blocks`（≤200 块/页；保留 id/kind/text/latex/needs_review/confidence/order/page/rotation/
  bbox/norm/source；空文字块与非法项丢弃）。
- 新增 `_local_ocr_page`：调用 `ocr.recognize_image(..., include_blocks=True)`，返回文字 + 内容块 + 提示；
  `_local_ocr_page_text` 保留为兼容包装。
- 视觉模型超时/失败 → `_ocr_fallback_entry(..., blocks=)` 在保留本地文本的同时带上内容块（`source=local_ocr`）；
  页面落库（`_page_entry`/`_normalize_ocr_pages`）保留 `blocks`，旧页面不新增空键；视觉成功的页不冒充块来源。
- 单测：块规范化/截断、页结构往返、fallback 带块、`include_blocks=True` 调用、`_save_ocr_pages` 持久化后可读回。

## 6. pyKT 离线评估协议（`scripts/integration/pykt_export.py`）

- 只读 SQLite（`mode=ro`）、不联网、不训练；**去标识化盐必须显式提供**（`--salt` 或 `STUDY_PYKT_SALT`），
  缺失时拒绝导出并返回码 2（中文提示），绝不输出未哈希用户标识。
- JSONL 字段：`user_key=sha256(salt+":"+user_id)[:16]`、`item_key`(统一引用)、`item_version`、
  `kc_keys`(知识点 id)、`timestamp`、`label`(1/0)、`source_key`、`prompt_state`、`reveal_state`、`self_report`、
  `evidence_version`；跳过 pending/unknown/自评/孤儿/缺引用/缺时间行；稳定排序；不含用户名/题干/答案。
- `evaluate_thresholds`：用户数、总事件、每用户事件（满足者数量）、每 KC 事件、标签覆盖率五项门控，
  返回 `{evaluation_allowed, gates, missing, note}`，不足时如实列出原因。
- `baseline_metrics`：平滑正确率 `(correct+1)/(attempts+2)` + PFA-lite（按 `(user_key,kc)` 仅用时间顺序历史，
  当前事件处理完才入历史，无泄露），输出 predictions/brier/accuracy；BKT/DKT 留给独立环境训练（报告注明）。
- CLI：`--data-dir/--db/--out/--report/--salt/--since/--min-*`；报告默认 `screenshots/pykt-report.json`。
