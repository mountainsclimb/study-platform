## 1. 种子构建（`scripts/build_vocab.py`）

- 数据源：`skywind3000/ECDICT` 的 `ecdict.csv`（MIT，Copyright (c) 2025 Linwei；
  上游提交 `9c46923fb81a2eb6c264a3a1689562ea7bc56b6a`）。
- 筛选：只保留小写单词（允许 `'`、`-`、空格，≤64 字符）且释义非空；`tag` 含 `gk`
  的高考词优先，按 `frq` 升序补齐到 8000；同词去重；最终按 `(frq, word)` 稳定排序。
- 字段白名单：`word` / `phonetic` / `translation` / `pos` / `tag` / `collins` /
  `oxford` / `bnc` / `frq` / `exchange`；`detail` / `audio` 不使用；释义限 800 字符。
- 产物：
  - `app/data/vocab_seed.json`（8000 条，约 2.3MB）；
  - `app/data/vocab_seed.LICENSE`（ECDICT MIT 全文）；
  - `app/data/vocab_seed.README.md`（来源提交、条数、字段、筛选口径、种子 SHA-256）。
- `--check` 重建并与磁盘种子逐字节比对、核对 README 登记的 SHA-256；首次运行可自动
  下载到 `%TEMP%\zhixu-ecdict-cache\`，`--source` 支持离线 CSV。

## 2. 后端（`app/vocab.py`）

- 表：
  - `vocab_items`：词条（`word` 唯一 + 十个白名单字段 + `seed_sha`）；
  - `vocab_cards`：用户词汇卡（`state_json/due_at/last_rating/reps/lapses/version/
    archived`，`(user_id, word)` 唯一，`(user_id, archived, due_at)` 索引）；
  - `vocab_ratings`：评分幂等日志（`(user_id, idempotency_key)` 唯一），
    为满足方案“idempotency_key 幂等重放”而新增的内部表，不改既有 `review_cards`。
  三张表均登记进 `app/db.py` 的 `_ID_TABLES`。
- `init_vocab()`：幂等建表，并解析/缓存种子元信息（按文件 mtime/size 失效）；
  **不直接写 8000 条**。首次访问词表/词汇卡时由 `_ensure_seed_loaded()` 按
  种子 SHA-256 判断是否需要整批事务写入；`meta`/`stats`/首页统计不触发装载。
  种子缺失/不可解析时只把模块标为 `available:false`，不阻塞应用启动。
- 路由 `/api/vocab`（均需登录）：
  - `GET /meta`：可用性、条数、种子 SHA、来源提交、字段；
  - `GET /items?tag&q&page&limit`：标签/关键词/分页，`frq` 升序；
  - `POST /cards`：加入复习（新建 due=now；归档卡重新激活）；
  - `GET /cards/due?limit&include_future`；`GET /cards/{id}`；
  - `POST /cards/{id}/ratings`：复用 `study_review.schedule()` 四档排程，
    版本乐观锁（409）、`idempotency_key` 重放不重复写；评分日志落 `vocab_ratings`；
  - `GET /stats`：总数/今日到期/各状态计数；
  - `GET /export`：当前用户非归档词汇 → Anki 牌组（genanki 可选依赖）。
- 首页：`app/home_stats.py::build_home()` 新增加法键
  `vocab: {available, due_today, total}`，既有 `review` / `personal` 字段不变。

## 3. 前端（`web/js/pages/vocab.js`）

- 路由 `#/vocab`（登录可见），在 `main.js` 注册、`state.js` 的「工具」分组加入导航。
- 页面：三项统计（已加入/今日到期/词表总量）、今日复习卡（先“显示释义”，再用
  `reviewRating` 四档评分）、词表浏览（关键词 + 高考/四级/六级/考研标签 + 分页 +
  加入复习）、Anki 导出。
- 评分请求带 `card_version` 与幂等键；409 时拉取最新卡交还组件，不伪造新日期。
- 首页行动卡新增「词汇本」（总数 + 今日到期）；样式 `web/styles-vocab.css`，
  文案 `vocab.` 命名空间（38 键 zh/en 成对）。
