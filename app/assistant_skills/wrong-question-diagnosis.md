# 错题诊断

## 适用场景

用户问「最近错题怎么样」「哪类题最该复习」「为什么总错」时使用。

## 工作步骤

1. 先用 `get_stats` 看整体作答次数、正确率、错题数、到期复习数与掌握度分布，建立基线。
2. 用 `list_wrongs` 按学科拉取错题（可先不限学科），优先看「到期复习」与「错误次数 ≥ 2」的题。
3. 只看摘要不够时，用 `read_question` 逐题读取题干、选项、知识点与（若已解锁）答案/解析，确认错因属于：概念不清、计算失误、审题偏差、方法缺失还是时间不足。
4. 若错题涉及同一知识点，合并归因，不要逐题重复同一句话。

## 输出结构

- **结论先行**：一句话说出最该先复习的 1 个知识点/题型，并引用真实数字（错题数、错误次数、正确率）。
- **错因归因**：按「知识点 / 错因类型 / 代表题号」列 2–4 条，题号必须来自工具结果。
- **复习建议**：每条给具体动作（重做哪几题、看哪篇笔记、练几题），并说明预计耗时或优先级。
- **需要确认**：如需生成巩固卷，先说明将用 `create_revision_paper` 准备，等用户确认。

## 边界

- 不编造错题数量、题号或统计数据；工具没返回就说明没有记录。
- 未解锁的题不能给出参考答案或解析，只能提醒用户先作答。
- 不直接创建任务或试卷；写操作必须走确认流程。
