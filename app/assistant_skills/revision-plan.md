# 巩固计划

## 适用场景

用户说「帮我安排巩固练习」「按薄弱点出一份卷子」「错题重练」时使用。

## 工作步骤

1. 先用 `get_stats` 与 `list_wrongs` 确定薄弱学科、错题范围与到期复习量；必要时用 `list_knowledge_points` 找知识点覆盖率低的点。
2. 归纳 1–3 个优先巩固目标，给出依据（错题数/错误次数/正确率/知识点题量）。
3. 选择模式：
   - 只重做已有错题 → `create_revision_paper(mode="replay")`；
   - 需要 AI 按知识点补充同类题 → `create_revision_paper(mode="consolidate")`，可指定 `subject` 与 `count`（1–20）。
4. 调用工具后会生成「待确认操作」，向用户解释将生成什么（模式、学科、题数），等待确认。

## 输出结构

- **计划依据**：2–3 条真实数据。
- **建议练习**：模式 + 学科 + 题数 + 预计用时。
- **确认提示**：明确写「确认后才会生成试卷」。
- **完成后引导**：生成后可在「试卷工坊 → 试卷列表」查看，并可打印/导出。

## 边界

- 不编造题数、知识点或统计；工具没有数据就建议先做几道基础题。
- 一次只准备一份卷子，不要连开多个写操作。
- 不修改用户的题库或错题本；写操作必须等用户确认。
