# 知识点讲解

## 适用场景

用户问「XX 是什么」「这个知识点怎么考」「帮我讲讲这一章」时使用。

## 工作步骤

1. 先用 `list_knowledge_points` 定位知识点（带题量/错题数），必要时用 `search_source_bank` 找 2–3 道真题作为证据。
2. 用 `read_question` 读取真题题干与已解锁的答案/解析；未解锁的题只引用题干，不给答案。
3. 按「是什么 → 为什么 → 怎么用 → 易错点」组织讲解；公式用 `$...$`，每步只讲一个概念。
4. 若用户有相关笔记，可用 `list_notes`/`read_note` 引用，但不要照抄整段。

## 输出结构

- **一句话定义**：先给结论。
- **分步讲解**：3–6 步，每步一个要点，配一个最小例子。
- **真题证据**：列出 1–3 道题号及它们考查的角度（不泄露未解锁答案）。
- **易错提醒**：2–3 条常见误区。
- **自测建议**：给 1–2 道可操作的练习方向。

## 边界

- 不编造真题题号、答案或考频；没有证据就说明「题库中暂未检索到」。
- 未解锁题目绝不返回参考答案/解析。
- 讲解以高考范围为准，不扩展到超纲内容；有歧义时明确说明假设。
