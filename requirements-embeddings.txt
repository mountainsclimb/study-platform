# 可选依赖：本地向量与重排（app/ai/embeddings_local.py、app/ai/rerank.py）。
# fastembed 为 Apache-2.0，基础依赖 numpy / onnxruntime / tokenizers / huggingface-hub /
# loguru / pillow / mmh3 / py-rust-stemmers，无 torch。见 THIRD_PARTY_NOTICES.md。
# 不进生产镜像；需要时安装：
#   pip install -r requirements-embeddings.txt
# 启用开关：STUDY_EMBEDDING_MODE=local；重排加 STUDY_RERANK=on（默认均关闭）。
#
# 模型由部署方预置，不进仓库与镜像（来源以 fastembed 0.9.1 注册表为准）：
#   <data>/models/embeddings  → Qdrant/bge-small-zh-v1.5（MIT，512 维）
#                               目标文件 model_optimized.onnx，另需 config.json、tokenizer.json
#   <data>/models/rerank      → BAAI/bge-reranker-base（MIT）
#                               目标文件 model.onnx，另需 config.json、tokenizer.json
# 目录可用 STUDY_LOCAL_EMBEDDING_DIR / STUDY_LOCAL_RERANK_DIR 覆盖。
# 支持三种布局：平铺目录、模型名子目录、huggingface_hub 缓存
# （models--Qdrant--bge-small-zh-v1.5/snapshots/<rev>/）。应用会定位实际快照并通过
# specific_model_path 加载；无关 *.onnx 不再算可用，缺文件时状态接口会列出文件名。
